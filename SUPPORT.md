# Support

OneLink Collect is a testnet hackathon project. Support is provided through
GitHub issues for reproducible product, documentation, and developer workflow
problems.

## Before Opening an Issue

Please check:

- [`README.md`](./README.md) for the verified product scope.
- [`docs/LAUNCH_READINESS.md`](./docs/LAUNCH_READINESS.md) for live proof and
  known limits.
- [`docs/SECURITY_REVIEW.md`](./docs/SECURITY_REVIEW.md) for dependency and
  repository security posture.

## Public Issues

Use GitHub issues for:

- Reproducible UI bugs.
- Documentation gaps.
- Local setup problems.
- Non-sensitive feature requests.

Include the browser/device, steps to reproduce, expected behavior, actual
behavior, and screenshots when relevant.

## Security Issues

Do not open a public issue for vulnerabilities or leaked credentials. Use
GitHub private vulnerability reporting as described in [`SECURITY.md`](./SECURITY.md).

## Scope Boundaries

OneLink is currently a testnet product. It does not provide mainnet payment
support, fiat/card processing, Solana checkout, or a live Circle Gateway
unified-balance route.
