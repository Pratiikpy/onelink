# Code of Conduct

## Standard

OneLink is an open technical project. Contributors and maintainers are expected
to communicate respectfully, give actionable feedback, and keep discussions
focused on improving the product and its security.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, publishing private information, spam, or intentionally unsafe advice
about wallets, secrets, or on-chain transactions.

## Scope

This standard applies to issues, pull requests, code review, documentation,
project discussions, and any public representation of OneLink.

## Reporting

For conduct issues, contact the repository maintainers privately through
GitHub. For security vulnerabilities, follow
[`SECURITY.md`](./SECURITY.md) and do not post exploit details publicly.

## Enforcement

Maintainers may edit or remove inappropriate contributions and restrict
participation when conduct threatens contributors, users, or the integrity of
the project.
